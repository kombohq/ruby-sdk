# PostAtsCandidatesRequestBodyAktiv

Whether the candidate is created as active (`Ja`) or inactive (`Nein`) in Coveto. If omitted, Coveto applies its default (active).

## Example Usage

```ruby
require "kombo"

value = PostAtsCandidatesRequestBodyAktiv::JA
```


## Values

| Name   | Value  |
| ------ | ------ |
| `JA`   | Ja     |
| `NEIN` | Nein   |
