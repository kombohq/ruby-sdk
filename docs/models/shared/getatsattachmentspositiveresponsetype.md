# GetAtsAttachmentsPositiveResponseType

What the file is used for in the ATS. Anything that is neither a CV nor a cover letter is reported as `OTHER`.

## Example Usage

```ruby
require "kombo"

value = GetAtsAttachmentsPositiveResponseType::CV
```


## Values

| Name           | Value          |
| -------------- | -------------- |
| `CV`           | CV             |
| `COVER_LETTER` | COVER_LETTER   |
| `OTHER`        | OTHER          |
